# AI Agent Configuration for Solucimob Calc

> Configuration and capabilities for AI-assisted calculation service development.

## 🤖 Agent Capabilities

### Code Understanding
- **Express.js**: Routing, middleware, controllers, error handling
- **MongoDB**: Schema design, queries, connections
- **Microservices**: Service-to-service communication, HTTP clients
- **Calculations**: Complex business logic, validation
- **Testing**: Jest, mocking HTTP calls, integration tests
- **Node.js**: Async/await, promise patterns, error handling

### Development Tasks Agent Can Perform

✅ **Can Help With**:
- Creating Express routes and controllers
- Implementing calculation algorithms
- Setting up MongoDB schemas and queries
- Creating HTTP client for config service
- Implementing error handling and validation
- Writing Jest unit and integration tests
- Adding caching for performance
- Implementing retry logic for resilience
- Logging and debugging
- Performance optimization
- Docker containerization

❌ **Not Recommended**:
- Hardcoding calculation rules (fetch from config)
- Bypassing config service for rules
- Skipping input validation
- Making synchronous calculations for large datasets
- Ignoring service failures gracefully

---

## 🛠 Recommended Skills

### Skill 1: Endpoint Creation
**When**: Adding calculation endpoint
**Process**:
1. Create route in routes file
2. Create controller with request validation
3. Call service with validated data
4. Handle errors with try-catch
5. Return consistent response format

### Skill 2: Config Service Integration
**When**: Fetching external rules/parameters
**Process**:
1. Create configService with HTTP client
2. Implement methods for each rule type
3. Add retry logic for failures
4. Cache results to reduce calls
5. Test with mocked config service

### Skill 3: Complex Calculations
**When**: Implementing business logic
**Process**:
1. Break down into smaller functions
2. Validate inputs at each step
3. Add unit tests for each function
4. Document assumptions
5. Optimize for performance

---

## 🔑 Key Concepts

- **Microservice**: Focused business domain service
- **Layered Architecture**: Clean separation of concerns
- **Config Integration**: Externalize business rules
- **Error Handling**: Proper HTTP status codes and messages
- **Caching**: Reduce external service calls
- **Async/Await**: Non-blocking calculations
